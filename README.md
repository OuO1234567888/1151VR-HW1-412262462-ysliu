4. 說明製作流程和相關操作 
在Hierarchy右鍵新增一個立方體，對其平移、旋轉和伸縮，在Asset Store下載一個3D模型並導入到專案中，因為渲染管線不同，所以導入的模型呈現粉紅色，在頂部功能列的 Window > Rendering > Render Pipeline Converter 轉換後便恢復正常。
